# Что полезного нашли в Kaggle discussions

Основной снимок собран **6 октября 2026, 10:47:56 UTC** через официальный anonymous frontend API: 161 тема, 890 уникальных message records, из них **853 доступных текста** и **37 удалённых/пустых placeholders**. Сбор охватывал доступные текстовые сообщения на тот момент. Картинки, видео, внешние attachments и Discord систематически не проверялись; недоступные тексты не считаем прочитанными.

[CSV-реестр всех 161 тем на 6 октября](../assets/discussions_snapshot_2026-10-06.csv) содержит название, ссылку, категорию, наш короткий пересказ, тип источника и счётчики охвата. Полные сообщения не публикуем. Поле `source_confidence` помогает отличить ответ организатора от результата или предположения участника. Это датированный снимок форума.

7 октября сделали **ограниченное обновление**: две index pages показали текущий counter **162 темы**; выборочно прочитали новые сообщения в нескольких изменившихся ветках и проверили четыре public notebooks. Это не повторный полный просмотр всех новых текстов. В [external-data clarification](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/743416#3534071) появились новые participant follow-ups, но проверенные ответы не добавили host ruling по MRNet, SKM-TEA или fastMRI. Условную формулировку OAI сохраняем.

Появился новый проверяемый кандидат: [RSNA Knee Tri-Specialist Superstack v1](https://www.kaggle.com/code/sujanmajhisuzan/rsna-knee-tri-specialist-superstack?scriptVersionId=355737240) имеет **0.945** в официальной Kaggle score metadata. Проверены exact-v1 source, public input mounts без private placeholders и доступность дополнительного [meniscus specialist dataset](https://www.kaggle.com/datasets/renta0426/rsna-knee-public0033-meniscus-bag-v1), опубликованного 2 сентября. Полный scoring мы не воспроизводили. Это combined stack с meniscus bag и target-specific blend; единственный score не отделяет вклад каждого изменения.

Manifest специалиста прямо указывает `fold_safe_oof: false`, а config — обучение на всех 4349 weak studies. Его готовые predictions не дают clean weak validation. Для переноса идеи нужен собственный held-out retraining; готовые target weights не считаем доказанной настройкой для нашей модели.

Практический порядок остаётся прежним: закончить frozen OrthoFoundation, сравнить attention и mean+max на одном feature bank, затем проверять sampling и meniscus bag при одинаковых splits и labels. Прочитанный код OrthoFoundation подтверждает авторский no-RoPE forward; канонический RoPE остаётся отдельной абляцией. Новый public 0.945 расширяет список публичных кандидатов с проверенными inputs, но не меняет статус нашего завершённого baseline 0.944 и не даёт измеренного выигрыша OrthoFoundation.
