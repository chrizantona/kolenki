# Что мы уже сделали

## Задача и данные

Один пример — целое MRI-исследование колена. Внутри несколько **серий**, снятых в разных плоскостях и режимах; серия состоит из 2D-срезов в DICOM. Модель выдаёт 12 независимых вероятностей для исследования: ACL, MCL, Medial Meniscus, Lateral Meniscus, Medial OA, Lateral OA, PF OA, Effusion, Synovitis, Baker's, Contusion, Fracture. Несколько патологий могут присутствовать одновременно.

Метрика — средний ROC AUC по 12 целям. Это оценка порядка прогнозов внутри каждого класса; подбор единственного порога 0.5 для сабмита её не улучшает. В скрытом test нет текстов MRI-отчётов: итоговая модель должна работать по изображениям и разрешённым метаданным. [Описание соревнования](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/overview), [данные](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/data).

## Собственный ConvNeXt-reader

Мы взяли полный публичный checkpoint `fold0` GoodPJ, уже обученный для этой задачи, и дообучили **энкодер и голову**. Это warm start; мы не обучали всю систему с нуля. ConvNeXt-Tiny — сверточный энкодер изображения. Его исходная классификационная голова удалена; на выходе каждого окна получаем 768 признаков.

Путь данных в reader:

```text
DICOM → упорядоченный volume → 3 соседних среза как 3 канала
      → ConvNeXt-Tiny: 768 признаков на окно
      → projection 768 → 384 + embedding серии и положения
      → TransformerEncoder: 2 слоя, 8 attention heads
      → 12 отдельных attention pooling
      → 12 logits → sigmoid
```

Здесь **2.5D** означает три соседних среза на входе 2D-энкодера. Эти каналы содержат разные глубины MRI. Transformer затем объединяет окна всего исследования; отдельный pooling позволяет каждому диагнозу выбирать свои информативные окна.

| Компонент | Фактическая настройка |
|---|---|
| Серии | 6 слотов: 3 плоскости × наличие/отсутствие fat suppression; пропуски маскируются |
| Повторные серии в одном слоте | Случайная серия при обучении; серия с наибольшим числом срезов при inference |
| Cache | Центрированный FOV 153.6 mm, spacing 0.4 mm/pixel, 384×384, до 64 срезов |
| Подготовка | Каноническая ориентация; порядок по физической позиции; нормализация интенсивности по percentiles 1–99.5; uint8 |
| Вход энкодера | 3×256×256; при оценке crop 92% поля cache, около 141 mm |
| Sampling | 8 тройных окон на слот при обучении, 12 при оценке; максимум 48/72 окон на исследование |
| Аугментации | Геометрические и яркостные преобразования, согласованные внутри серии |
| Положение | Нормализованная координата 0…1; отдельного embedding физической дистанции в mm пока нет |

При исходной серии длиннее 64 срезов cache равномерно сокращает её. Поэтому соседние срезы cache не всегда являются соседними нативными срезами MRI.

## На чём и как обучали

У 58 исследований есть официальные Gold-метки; остальные **4349** использованы с weak labels из публичных извлечений MRI-отчётов. В точном рецепте четыре источника: [Steven v4](https://www.kaggle.com/datasets/stevenleehans/rsna-knee-llm-report-labels), [Pilkwang v2](https://www.kaggle.com/datasets/pilkwang/rsna-knee-llm-labels), [Lixin](https://www.kaggle.com/datasets/lixin73/rsna-knee-llm-report-labels-sol56), [Qwen v1](https://www.kaggle.com/datasets/laymond/rsna-knee-abnormality-qwen3-8b-weak-labels). Усредняем доступные значения по каждому классу и ограничиваем target диапазоном `[0.01, 0.99]`. Для Qwen v1 исходный рецепт использует `__label`.

Мы сами эти LLM-метки не генерировали. Четыре таблицы также не равны четырём независимым учителям: Steven v4 уже включает Lixin. Это отдельная гипотеза для ablation.

| Параметр / результат | Значение |
|---|---:|
| Эпохи | 2 фиксированные, завершены |
| Loss | BCEWithLogitsLoss с soft targets |
| Optimizer | AdamW, weight decay 0.02 |
| Learning rate | Энкодер `1e-5`; голова `5e-5` |
| Batch | 1 исследование, accumulation 8; effective batch 8 |
| Scheduler | Произведение линейного warmup и cosine factor |
| EMA | Адаптивный decay с верхней границей 0.998 |
| Успешные optimizer updates | **1086**, пропусков AMP: **0** |
| Время обучения | 2386.65 s, около 40 min |
| Peak GPU memory | 4.72 GB |
| Обработано | 4344 исследования за эпоху; объединение двух эпох покрывает все 4349 |

Пять исследований за эпоху выпадают из неполной accumulation-группы; за две эпохи каждое weak-исследование было обработано хотя бы раз. Все **58 Gold исключены** из нашего дообучения. Выбран итоговый EMA после двух эпох; выбор лучшей эпохи по Gold не проводился. Проверено изменение всех 180 tensors энкодера и 39 tensors головы относительно стартового checkpoint.

Итоговый diagnostic Gold macro AUC reader: **0.911160**. Это не сертифицированная чистая OOF-оценка: происхождение splits исходного knee checkpoint недостаточно известно, а публичные авторы меток уже использовали эти 58 исследований. Сравнивать это число с public score целого ансамбля напрямую нельзя.

## Какие ещё модели входят в сабмит

Остальной ансамбль взят из публичного GoodPJ V2. Эти компоненты мы пока не переобучали:

| Ветка | Состав и агрегация |
|---|---|
| DINOv2 | ViT-small, **20** готовых членов; усреднение percentile ranks |
| A5 | DINOv3 ViT-small, **5 folds**, 16-channel slice input; blend 0.52 A5 / 0.48 DINO в соответствующей ветке |
| RadImageNet | ResNet50 с готовыми heads/layouts; target-wise calibrator использует ранги, взаимодействия и protocol counts |
| Raptor | CoAtNet, 3 checkpoints и 4 представления; веса views 0.60 / 0.10 / 0.10 / 0.20 |
| Дополнительные CoAtNet | Четыре families: `resgated_top3`, `global96_top3`, `d4_swa3`, `repairv1_top3` |
| ConvNeXt reader | **3** checkpoints: наш EMA вместо публичного fold0, публичные fold1 и fold2 |

Публичные ветки объединяются несколькими target-specific rank blends. В финале обозначим их результат `S`, а среднее вероятностей трёх ConvNeXt-readers — `C`:

```text
final = rank(0.70 × rank(S) + 0.30 × rank(C))
```

`rank` вычисляется отдельно по каждой из 12 колонок как percentile rank. Собственная модель — один из трёх reader checkpoints внутри ветки с весом 30%. Из-за вложенных рангов это не постоянный линейный вклад «ровно 10%».

## Что реально получили

Наше воспроизведение публичного baseline: **0.943**. Сабмит с нашим дообученным reader: **0.944**, Kaggle submission `56891310`, run `355883025`, scoring `COMPLETE`, проверено 2026-10-07 08:46 UTC. [Наш notebook](https://www.kaggle.com/code/alanchoo/rsna-knee-944-finetuned?scriptVersionId=355883025) приватный.

На трёх доступных demonstration studies изменились все 36 сырых прогнозов reader, но финальный rank-CSV сохранился: маленькое число примеров может сохранить порядок при изменении вероятностей. Полный hidden rerun завершился и дал 0.944. Один такой результат ещё не устанавливает причинный или устойчивый выигрыш дообучения.
