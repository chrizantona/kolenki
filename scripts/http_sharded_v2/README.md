# HTTP sharded V2 transport sources

These source files are byte-identical to the prepared full HTTP V2 pipeline.
The [eight notebooks](../../notebooks/orthofoundation/http_sharded_v2/) embed
all transport sources and the eight pinned scientific modules, so they retain
the complete generated execution code.

The private builder uses absolute paths in the original local workspace and is
omitted here. Its SHA and the original 25 localhost/CPU fixture results are in
the [preparation receipt](../../experiments/orthofoundation_http_sharded_v2/preparation_receipt.json).
Those fixtures were run against the private preparation; the public copies have
received static byte/payload verification, without another execution.

`transport.py` copies small receipt files from verified global metadata and
streams an exact original ZIP into owned `/tmp`. `download.py` uses the unchanged
reviewed Range block from `transfer_reviewed.py`, with no upload branch or account
authentication. `parent_guard.py` bounds the complete owned process group and
removes its scratch after success, timeout or preparation failure.

`forecast.py` accounts for all seven ZIP downloads, startup, image extraction and
pilot reserve. `approval.py` requires the owner's actual V2 MRI pilot proof,
matching source/identity pins, a fitting measured forecast and recent quota.
Private read jobs and owner approval files are excluded from Git.

The exact source-index pins describe ZIP outputs V1 separately from underlying
NPY versions. Source5 preserves its fresh-DICOM provenance. Full training remains
unobserved; follow the [experiment status](../../experiments/orthofoundation_http_sharded_v2/STATUS.md).
